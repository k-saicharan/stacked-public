# Tests

These cover the parts that have to be right: the pace and daily-target
arithmetic, overtime classification against the rostered shift window,
stops-per-pallet density, and export/import round-tripping.

Four further tests run in the private working repository and are not included
here. They replay the author's real logged shift exports through the shift
predictor and the overtime classifier, so they need those export files to run.
Those exports are personal working records and are deliberately not published.
