# Screenshots

`analysis-view.png` is the Analysis view rendered from `dashboard/index.html`,
using the synthetic demo dataset that ships with this repository. No real
shift records appear in it.

App screenshots (Log keypad, session summary, stats, schedule) are captured on
a physical device, per `play-store/README.md`. They are not generated from the
web build, because the app ships to Android and the store listing requires
real-device captures at 1080x1920 or larger.
